# 🎯 System-Wide Common Goal

## Primary Objective
To rapidly build a highly accessible, blazing-fast, and cohesive web application that delivers an exceptional user experience across all devices.

## Core Directives for All Agents
1. **Unify the User Experience**: Every design and architectural decision must prioritize a seamless, intuitive, and accessible experience for the end-user.
2. **Collaborative Harmony**: You are part of a multi-agent system. Ensure your outputs (whether components, styles, or logic) integrate seamlessly with the artifacts produced by other agents.
3. **Performance First**: Prioritize lightweight solutions, minimal bundle sizes, and optimal rendering performance.
4. **Maintainability**: Document your rationale and write clean, semantic code that can be easily understood by both humans and other AI agents.
